## Cross-cutting guardrails (apply throughout)

- [ ] Every DB write goes through a service, takes an explicit `actor`, and records an audit event in the same transaction (routers never write).
- [ ] Enum-like values only from `app/constants.py`; schema stays engine-neutral (JSON column, no arrays/partial indexes).
- [ ] Immutable data patterns; files 200–400 lines (800 max), split by feature.
- [ ] Secrets only via env; `SECRET_KEY` required at boot; `ADMIN_PASSWORD` never logged; `.env` git-ignored.
- [ ] Security: argon2id, ≥10-char passwords, HttpOnly+SameSite=Lax cookie, `X-Requested-With` on mutations, login rate limit, single-use hashed tokens.
- [ ] Mandarin text preserved only in `provenance`; UI and item text English-only.
